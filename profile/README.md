# .github Repository

This repository contains organization-wide configuration files for IronCloudForge.

GitHub uses a special `.github` repository to store shared resources, including:

- Default issue templates
- Default pull request templates
- Community health files (CONTRIBUTING, CODE_OF_CONDUCT, etc.)
- Optional organization profile content

Keeping this repository allows the organization to manage consistent standards and templates across all projects.

This repository is not intended for source code and can generally be ignored by contributors.
