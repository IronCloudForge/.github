# IronCloudForge .github Repository

This repository contains organization-wide configuration and community health files for IronCloudForge.

GitHub uses a special `.github` repository to store shared resources, including:

- Default issue templates
- Default pull request templates
- Community health files (CONTRIBUTING, CODE_OF_CONDUCT, etc.)
- Optional organization profile content

Keeping this repository allows IronCloudForge to maintain consistent standards, documentation patterns, and governance practices across all projects.

## About IronCloudForge

IronCloudForge is an open‑source research organization focused on advancing AI‑supported governance models, policy analysis tools, and federal cloud compliance automation.

Current active research repositories include:

### **Agrogentic**
Open‑source research into agentic AI governance architectures — including ASRs, ADRs, and a NIST‑aligned four‑layer model for federal and public‑sector systems. The project explores how structured reasoning and agentic decision support can be safely introduced into high‑assurance environments.

### **policyforge**
Open‑source research into corpus‑grounded, provenance‑preserving extraction and analysis of USDA policy using linguistic, deontic, and AI‑assisted methods. The project investigates structured policy interpretation and automated compliance mapping.
